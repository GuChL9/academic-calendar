# 学期日期表

这个程序是为我后续打算制作的一个应用积累基础功能的一次尝试, 目标是做一个从空白日历开始制作校历的小工具

## 本地运行

需要 Node.js 20 或更新版本

```sh
node serve.js
```

打开 <http://127.0.0.1:3000/>, 选择学年和学期后点击 "生成日期表"

## 日期范围

学年填写起始年份, 然后选择日期, 日历范围按下表确定

| 学期 | 日期范围 |
| --- | --- |
| 秋冬 | 起始年 7 月 1 日至次年 2 月末 |
| 春夏 | 次年 1 月 1 日至 8 月 31 日 |

日期按周一至周日纵排, 各周横排, 首尾不足一周的格子留空, 月份表头按每列第一个日期确定

## 教学周

在 "第一教学周周一" 中填写当前日期范围内的周一, 点击 "生成日期表" 后会定位到第一教学周; 留空时只显示日期

秋冬和春夏均按连续的两个 8 周编排, 冬学期和夏学期重新从第 1 周计数, 起点之前和 16 周之后不标教学周, 只显示表格日期范围内的部分

当前设置在刷新页面后重置
